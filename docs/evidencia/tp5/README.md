# TP5 — Registro de sesiones reales (PENDIENTE)

Esta carpeta no contiene pruebas con personas. No deben generarse resultados ficticios.

Para cada usuario real U1, U2 y U3 (sin nombre ni correo), documentar:

- Día/hora y dispositivo/navegador; si la app estaba instalada, permiso y conexión.
- Evento utilizado: ID, fuente, fecha de publicación, fecha de carga, horario del evento, departamento/carrera y si le interesaba al usuario.
- Situación planteada (sin decirle dónde tocar) y tareas acordadas **por el equipo**, sin intervenir durante el recorrido.
- Qué hizo: si apareció el aviso del sistema, lo tocó, entró directo a la ficha, leyó fecha/hora/lugar, activó el recordatorio o encontró el enlace externo; errores, dudas, tiempos y solicitudes de ayuda.
- Preguntas abiertas no inductivas al terminar; respuestas literales y conclusiones separadas.
- Consentimiento para grabar si se usan grabaciones; evitar información personal innecesaria.
- Registro de sesgos del entorno (demo, push no entregado, evento irrelevante) y no interpretar como hipótesis confirmada lo que no se observó.

Los datos de apertura registrados por la app pueden cruzarse con las notas, pero `push_accepted` solo significa que el proveedor de push aceptó el paquete, no que el usuario lo recibió o leyó. No compartir claves privadas ni suscripciones contenidas en `server/data/db.json`.
